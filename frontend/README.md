# GameVault - Proyecto Web (React & Node.js)

Bienvenido al repositorio de la versión Web y Backend de GameVault, desarrollado por Estela.

## Estructura del Proyecto
Este repositorio contiene dos partes principales:
- `/frontend`: Interfaz de usuario creada con React.
- `/backend`: Servidor y conexión a la base de datos MySQL.

## Instrucciones de Instalación y Uso

Para hacer funcionar este proyecto en tu equipo local, sigue estos pasos:

### 1. Base de Datos
- Asegúrate de tener MySQL instalado y ejecutándose.
- Ejecuta el script SQL incluido para crear la base de datos `mydb` y sus tablas.

### 2. Arrancar el Backend
Abre una terminal, entra en la carpeta del backend e instala las dependencias:
```bash
cd backend
npm install
npm run dev
